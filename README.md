# Лабораторна робота № 1 з курсу «Кросплатформні засоби програмування»

**Варіант 5:** Меню кафе

## Призначення
Програма читає записи з `data/input.csv`, перевіряє їх на коректність, обчислює статистичні показники та формує звіт у консоль і текстовий файл `out/report.txt`.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою (`;`). Файл кодується у UTF-8.
Формат запису: `постачальник (String); назва (String); категорія (String); ціна (double); вага в грамах (int); час приготування (int)`.

Приклад даних (`data/input.csv`):
Кав'ярня "Львівські круасани";Капучино;Напої;45.50;250;5
ФОП Петренко;Сирник домашній;Десерти;65.00;180;10
;Яблучний штрудель;Десерти;55.00;-200;10

## Збірка та запуск
Проєкт використовує Maven Wrapper для відтворюваної збірки.

**Перевірка та пакування:**
```bash
./mvnw.cmd verify
./mvnw.cmd package
```
**Запуск готової програми:**
```bash
java -jar target/lab01-1.0.0.jar
```
