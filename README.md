# Кавове меню (Лабораторна робота № 3)

**Автор:** Студент 3 курсу Національного університету "Львівська політехніка"
**Варіант:** 5 (Меню кафе)
**Предмет:** Конструювання програмного забезпечення

## Опис проєкту

Ця програма читає дані про позиції меню кафе з CSV-файлу, обробляє їх та генерує підсумковий звіт. У третій лабораторній роботі проєкт було розширено за допомогою спадкування та поліморфізму.

## Що нового у версії 3.0

- **Спадкування:** Створено абстрактний базовий клас `MenuItem`, який містить спільні поля (назва, ціна, вага тощо) та інваріанти.
- **Підтипи:** Реалізовано три класи-спадкоємці: `Dish` (Страва), `Drink` (Напій), `Dessert` (Десерт).
- **Поліморфізм:** Обчислення вартості позиції тепер виконується через поліморфний метод `calculateCost()`, який кожен підтип реалізує за власною формулою.
- **Enum:** Категорії меню суворо типізовані за допомогою перелічуваного типу `MenuKind`.
- **Рівність об'єктів:** Перевизначено методи `equals()` та `hashCode()` для коректного порівняння об'єктів та використання їх у колекціях типу `HashSet`.

## Як запустити

1. Переконайтеся, що ви знаходитесь у папці проєкту.
2. Для збірки та тестування: `.\mvnw.cmd clean test`
3. Для запуску: `.\mvnw.cmd compile exec:java "-Dexec.mainClass=ua.lpnu.kzp.Main"`
