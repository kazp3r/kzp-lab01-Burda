# Кавове меню (Лабораторна робота № 2)

КІ-304 Бурда О. В.
**Варіант:** 5 (Меню кафе)
**Предмет:** Конструювання програмного забезпечення

## Опис проєкту
Ця програма читає дані про позиції меню кафе з CSV-файлу, обробляє їх та генерує підсумковий звіт. У другій лабораторній роботі проєкт було переведено на об'єктно-орієнтовану архітектуру.

## Що нового у версії 2.0
* **Інкапсуляція:** Дані про страви тепер зберігаються у класі-сутності `MenuItem` із суворою перевіркою параметрів у конструкторі.
* **Безпека даних:** Усі поля `MenuItem` є `private final`, а модифікація об'єкта після створення неможлива (відсутні сеттери).
* **Контролер:** Усю логіку читання файлів та розрахунків винесено до `MenuController`, що розвантажило клас `Main`.
* **Record:** Підсумкова статистика надійно зберігається у незмінному `MenuSummary`.
* **Тести:** Додано `MenuItemTest` для перевірки валідації полів та обробки CSV-рядків.

## Як запустити
1. Переконайтеся, що ви знаходитесь у папці проєкту (`lab01`).
2. Для збірки та тестування: `.\mvnw.cmd clean test`
3. Для запуску програми: `.\mvnw.cmd compile exec:java "-Dexec.mainClass=ua.lpnu.kzp.Main"`
